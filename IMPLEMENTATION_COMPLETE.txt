💰 BUSINESS LOGIC IMPLEMENTED

Revenue Model:
  • Base subscription: 100₽/month/user
  • Device upgrade: 100₽ per additional device
  • Multi-device support (1 to 10 per user)

Payment Flow:
  1. User initiates purchase via Telegram
  2. Bot creates Yandex.Kassa invoice
  3. User pays online
  4. Yandex.Kassa sends webhook
  5. Subscription activated automatically
  6. User receives VPN config link
  7. User connects via Happ VPN app

Subscription Lifecycle:
  • Day 1-25: Full access
  • Day 26-30: Reminder notifications
  • Day 30+: Access revoked
  • Cleanup every 24 hours
